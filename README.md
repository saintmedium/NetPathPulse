# 🌐 NetPathPulse

> **Пульс вашей сети — на каждом узле маршрута.**

**NetPathPulse** — это современный визуальный аналог классического WinMTR. 
Программа объединяет `traceroute` и `ping` в реальном времени, показывая 
задержку и потери пакетов на **каждом хопе** между вами и целевым сервером — 
наглядно, в графиках и с понятной статистикой.

## ✨ Возможности

- 🚀 **Трассировка + пинг одновременно** — как в MTR, но с человеческим интерфейсом
- 📊 **Живые графики** задержки (latency) и потерь (packet loss) по каждому узлу
- 🎯 **Мгновенное выявление проблемного хопа** — сразу видно, где начинаются сбои
- 🔄 **Обновление в реальном времени** — статистика копится по ходу работы
- 🧭 **Понятная визуализация маршрута** — узлы, задержки, джиттер
- 💾 **Экспорт результатов** — сохраняйте отчёты для диагностики
- 🖥️ **Кроссплатформенность** *(в зависимости от вашей реализации)*
